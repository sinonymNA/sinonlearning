# Classroom Arcade acceptance checklist

- [ ] Arcade homepage, host, join, room, collection, shop, and developer lab routes.
- [ ] Shared server-authoritative room state, six-character codes, polling/reconnect, host controls, timers, scoring, and playlist transitions.
- [ ] Hot Potato: grouped play, server dictionary validation, hearts, random transfers, expiration, scoring.
- [ ] Quick Draw: synchronized compact strokes, secret prompts, guessing, timers, rotation, scoring.
- [ ] Last One Standing: server scoring, rounds, tie handling, consolation play, final showdown.
- [ ] Telephone: draw/describe/draw chain assignment, reveal, participation and voting.
- [ ] Imposter: exact private roles, question/answer phases, simultaneous reveals, vote/runoff, final guess.
- [ ] Party mode, cumulative leaderboard, coins, 12 cosmetics, pack opening, content sets/CSV.
- [ ] Developer lab with up to 39 bots and game-specific behavior.
- [ ] Automated tests, 35-client load test, browser verification, production build.
